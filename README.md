# 华夏风俗志 · 宋元民俗科普小程序

> 千年岁时，万般风物——翻开宋元时期的生活画卷。

一款面向学生和传统文化爱好者的微信小程序。第一期聚焦**宋元时期**，把节日、礼俗、饮食、服饰、市井娱乐等民俗整理成可浏览、可互动的内容。

## 为什么做这个项目

- 民俗知识散落在古籍和各类文章里，读起来枯燥，真假也难分辨
- 想用“数据驱动的内容结构 + 互动小游戏”，让历史内容更好读、更好玩，同时保持考据的严谨

## 功能

- **专题浏览**：当前 9 个宋元专题（元宵、清明、七夕、中秋、点茶、婚礼、瓦舍勾栏、服饰、诈马宴）
- **朝代筛选**：全部 / 宋代 / 元代
- **每日一俗**：按日期轮换一条民俗小知识，点击进入专题
- **元宵观灯专题**：鳌山灯、猜灯谜小游戏（10 题，支持输入答案、查看谜底、计分）、吃浮圆子（含宋诗与字词小注）
- **清明专题**：三节合一、“宋人的清明一日”时间线、清明玩家榜、民间讲究
- **转发分享**：一键转发任意专题

## 技术方案

- 微信小程序原生开发（WXML + WXSS + JavaScript），无后端，使用本地 JSON 风格数据
- **数据与页面分离**：只有一个通用详情页，所有专题通过 `sections` 数据渲染。新增专题只需要在 `data/customs.js` 里加一条，不用改页面代码

```js
{ id: 1, title: "元宵观灯", dynasty: "宋代",
  sections: [
    { title: "鳌山灯", paras: [...], quotes: [...], images: [...] },
    { title: "猜灯谜", type: "riddles", riddles: [...] },
    { title: "宋人的清明一日", timeline: [...] }
  ] }
```

- **灯谜小游戏**：用页面状态管理题序、输入、判定（猜中 / 再想想 / 看谜底）和得分
- **每日一俗**：用“当年第几天 % 条目数”轮换，无需服务器
- **视觉**：朱红 / 墨黑 / 米白 / 青绿配色；卷轴边框、灯笼、竖排谜面全部用 CSS 绘制，不依赖图片
